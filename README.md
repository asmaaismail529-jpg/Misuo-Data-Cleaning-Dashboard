# Messio Data Cleaning & Dashboard Project

## Project Overview
This project focuses on cleaning and preparing messy business data for **Messio company**, then building an Excel dashboard to extract meaningful insights.

## Data Issues
- Duplicate values
- Inconsistent naming (same category written in different ways)
- Missing values
- Incorrect data types
- Unstructured raw data

## Data Cleaning Process
- Removed duplicates
- Standardized categories
- Handled missing values
- Corrected data types
- Validated data accuracy

## Tools Used
- Microsoft Excel
- Data Cleaning techniques
- Pivot Tables
- Charts & Dashboards

## Outcome
- Clean and reliable dataset
- Clear KPIs
- Interactive dashboard supporting decision-making
